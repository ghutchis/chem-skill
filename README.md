# 🧪 chem-skill

An [LLM Agent Skill](https://agentskills.io/home) to provide basic cheminformatics to Claude and other models that use skills.

Generate 2D molecular structure images and interactive 3D conformer viewers from chemical names, SMILES, or InChI strings.

Most of the code was generated by Claude, with careful validation, error fixing, and OPSIN integration by Geoff Hutchison.

## ✨ Features

- **2D Structure Images** — Generate PNG or SVG molecular diagrams
- **3D Interactive Viewers** — Create HTML files with rotatable 3D models using 3Dmol.js
- **Multiple Input Formats** — Accepts chemical names, SMILES, or InChI strings
- **Offline Support** — Bundled OPSIN for chemical name resolution and 3Dmol.js for network-free 3D viewing
- **Batch Processing** — Convert multiple molecules at once
- **Customizable** — Control size, style, atom highlighting, and more

## 📦 Installation

For most agents, [download a zip](https://github.com/ghutchis/chem-skill/ archive/refs/heads/main.zip), attach to a conversation and ask to install it.

**NOTE:** To use [PubChem](https://pubchem.ncbi.nlm.nih.gov/) you will likely need to enable Claude or other LLM to allow network access to `*.nih.gov` sites. This is important for resolving common molecule names like "caffeine" or "aspirin" instead of systematic IUPAC names.

```bash
# Clone the repository
git clone https://github.com/yourusername/chem-vis.git
cd chem-vis

# Install dependencies
pip install rdkit pubchempy py2opsin
```

### Dependencies

| Package | Purpose |
|---------|---------|
| `rdkit` | Core cheminformatics (structure parsing, 2D/3D generation) |
| `pubchempy` | Chemical name → SMILES resolution via PubChem |
| `py2opsin` | Offline IUPAC name → SMILES conversion |

## 🚀 Quick Start

```bash
# Generate a 2D structure image
python scripts/chem_2d.py "caffeine" --output caffeine.png

# Generate an interactive 3D viewer
python scripts/chem_3d.py "caffeine" --output caffeine.html

# Generate both at once
python scripts/chem_vis.py "caffeine" --both --output-dir ./caffeine/
```

## 📖 Usage

### 2D Structure Images

Generate static molecular structure diagrams.

```bash
# Basic usage
python scripts/chem_2d.py "aspirin" --output aspirin.png

# From SMILES
python scripts/chem_2d.py "CCO" --input-type smiles --output ethanol.png

# SVG output with custom size
python scripts/chem_2d.py "glucose" --format svg --width 400 --height 400 --output glucose.svg

# Show atom indices
python scripts/chem_2d.py "benzene" --show-atom-numbers --output benzene_numbered.png

# Kekulé structure (explicit double bonds)
python scripts/chem_2d.py "benzene" --kekulize --output benzene_kekule.png
```

#### Options

| Option | Description | Default |
|--------|-------------|---------|
| `--input-type`, `-t` | Input format: `name`, `smiles`, `inchi` | `name` |
| `--output`, `-o` | Output file path | `molecule.png` |
| `--format`, `-f` | Output format: `png`, `svg` | `png` |
| `--width`, `-W` | Image width in pixels | `300` |
| `--height`, `-H` | Image height in pixels | `300` |
| `--kekulize`, `-k` | Show Kekulé structure | `False` |
| `--show-atom-numbers`, `-n` | Display atom indices | `False` |
| `--highlight-atoms` | Atom indices to highlight | `None` |

### 3D Interactive Viewers

Generate HTML files with rotatable, zoomable 3D molecular models.

```bash
# Basic usage
python scripts/chem_3d.py "dopamine" --output dopamine.html

# Ball-and-stick style
python scripts/chem_3d.py "serotonin" --style ballstick --output serotonin.html

# From SMILES
python scripts/chem_3d.py "CCO" --input-type smiles --output ethanol.html

# Use CDN instead of bundled 3Dmol.js (smaller file, requires internet)
python scripts/chem_3d.py "caffeine" --use-cdn --output caffeine.html

# Embeddable snippet (for inserting into existing web pages)
python scripts/chem_3d.py "aspirin" --embed --output aspirin_widget.html
```

#### Options

| Option | Description | Default |
|--------|-------------|---------|
| `--input-type`, `-t` | Input format: `name`, `smiles` | `name` |
| `--output`, `-o` | Output file path | `molecule_3d.html` |
| `--width`, `-W` | Viewer width in pixels | `500` |
| `--height`, `-H` | Viewer height in pixels | `400` |
| `--style`, `-s` | Render style: `stick`, `sphere`, `line`, `ballstick` | `stick` |
| `--conformers`, `-c` | Number of conformers to sample | `10` |
| `--no-optimize` | Skip MMFF geometry optimization | `False` |
| `--no-controls` | Hide style/spin buttons | `False` |
| `--embed` | Output snippet without HTML wrapper | `False` |
| `--use-cdn` | Load 3Dmol.js from CDN (requires network) | `False` |

### Unified CLI

Generate both 2D and 3D outputs with a single command.

```bash
# 2D only
python scripts/chem_vis.py "caffeine" --2d --output caffeine.png

# 3D only
python scripts/chem_vis.py "caffeine" --3d --output caffeine.html

# Both (saves to directory)
python scripts/chem_vis.py "caffeine" --both --output-dir ./caffeine/
```

## 🐍 Python API

### 2D Images

```python
from scripts.chem_2d import chemical_to_image, batch_convert

# Single molecule
chemical_to_image("caffeine", "caffeine.png", width=400, height=400)

# With options
chemical_to_image(
    "benzene",
    "benzene.svg",
    format="svg",
    kekulize=True,
    show_atom_numbers=True
)

# Batch conversion
chemicals = ["aspirin", "ibuprofen", "acetaminophen"]
results = batch_convert(chemicals, output_dir="./structures/", format="svg")
```

### 3D Viewers

```python
from scripts.chem_3d import chemical_to_3d, generate_conformer, generate_html_viewer
from scripts.common import get_smiles

# Simple usage
chemical_to_3d("caffeine", "caffeine.html", style="ballstick")

# Step-by-step for more control
smiles = get_smiles("caffeine", "name")
mol_block = generate_conformer(smiles, num_conformers=20)
html = generate_html_viewer(
    mol_block,
    title="Caffeine",
    width=600,
    height=500,
    style="ballstick"
)

with open("caffeine_custom.html", "w") as f:
    f.write(html)
```

### Multi-Molecule Comparison Page

```python
from scripts.chem_3d import generate_conformer, generate_html_viewer
from scripts.common import get_smiles

molecules = ["aspirin", "ibuprofen", "naproxen"]

page = '''<!DOCTYPE html>
<html>
<head>
    <script src="https://3dmol.org/build/3Dmol-min.js"></script>
    <style>
        .container { display: flex; gap: 20px; flex-wrap: wrap; padding: 20px; }
    </style>
</head>
<body>
<h1>NSAID Comparison</h1>
<div class="container">
'''

for name in molecules:
    smiles = get_smiles(name, "name")
    mol_block = generate_conformer(smiles)
    page += generate_html_viewer(
        mol_block,
        title=name.title(),
        width=350,
        height=300,
        embed=True
    )

page += '</div></body></html>'

with open("nsaid_comparison.html", "w") as f:
    f.write(page)
```

## 🔧 Troubleshooting

### "Could not find chemical"

- Check if network access is enabled to `*.nih.gov` sites for PubChem use.
- Check spelling (try both common and IUPAC names)
- Use SMILES directly: `--input-type smiles`
- Some trade names may not be in PubChem

### "Could not generate 3D conformer"

- Try `--no-optimize` to skip force field optimization
- Increase `--conformers` count for difficult molecules
- Some structures (metal complexes, unusual bonding) may not embed properly

### Poor 2D layout

- RDKit's 2D coordinate generation works best for typical organic molecules
- Very large or unusual structures may benefit from manual adjustment

### 3D viewer doesn't load

- By default, 3Dmol.js is bundled inline (no network needed)
- If using `--use-cdn`, check your internet connection
- Check browser console for JavaScript errors
